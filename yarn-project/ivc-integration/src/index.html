Log

The block-list excludes LOOKUP_READ_TAGS, LOOKUP_READ_COUNTS, and VK_PRECOMPUTED_POLY from GPU delegation. These columns concentrate every nonzero scalar into a single bucket (selectors are 0/1, lookup tags repeat the same value), which the MsmV2 pair-tree's "scalars must be random" contract does not guarantee. Empirically they cost ~5.8% of total CPU MSM time — keeping them on CPU is essentially free. See /tmp/zac-webgpu/chonk-delegate-eligible.md for the per-column safety analysis.
