ChonkApi::prove on the canonical ecdsar1+transfer_1_recursions+sponsored_fpc flow. Each button runs the prove N times on one reused backend and reports the median (with min–max and the per-run list). WASM runs every MSM on the multi-threaded CPU Pippenger; WebGPU delegates eligible MSMs to the GPU (a block-list keeps a few structured-scalar columns on the CPU); WebGPU (batch) additionally routes same-N batches of B ≥ 4 at n ≤ 217 through the BatchMsmV2 dispatch. The WebGPU cards cross-check their verification key against the last WASM run. Each card also reports peak memory: the WASM linear heap (the metric CI tracks), plus, for the WebGPU cards, the GPU VRAM the MSM bridge holds — the pool the WASM-only number can't see.
