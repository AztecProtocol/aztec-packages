# Security Policy

## Supported Versions

Only the most recent release of the Aztec packages is currently supported with security updates. Earlier versions may contain unpatched vulnerabilities and are not actively maintained.

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please submit it privately so that we can address it quickly and responsibly. Do **not** open public issues describing the vulnerability.

You can report vulnerabilities in one of the following ways:

- Use the **Report a vulnerability** link in the GitHub **Security** tab to create a private security advisory. This will allow project maintainers to triage and respond without exposing details publicly.
- If you do not have access to the GitHub private reporting workflow, send an email to **security@aztecprotocol.com** with a detailed description of the issue, steps to reproduce it, and any relevant logs or proof‑of‑concept code.

We will acknowledge receipt of your report within 5 business days and will work with you to assess the impact and plan a fix. Once the issue has been resolved and released, we will coordinate a public disclosure along with appropriate credit.

## Vulnerability Disclosure

We follow a coordinated disclosure process. Please provide us with a reasonable amount of time to resolve the issue before any public disclosure. We aim to provide an update on our remediation progress within 30 days of the initial report.

Thank you for helping to keep Aztec and its users secure.
