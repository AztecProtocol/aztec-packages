# Protocol Circuits API Documentation Generation

This script generates API documentation for the `noir-protocol-circuits` using `nargo doc`.

## Usage

```bash
# Generate docs for "next" version (default)
./generate_protocol_circuits_docs.sh

# Generate docs for a specific version
./generate_protocol_circuits_docs.sh v1.0.0
```

Or from the docs root:

```bash
./scripts/protocol_circuits_docs_generation/generate_protocol_circuits_docs.sh [version]
```

## Requirements

- `nargo` must be available in PATH or set via `NARGO` environment variable
- The `noir-protocol-circuits` workspace must be at `../noir-projects/noir-protocol-circuits` relative to the docs folder

## Output

The generated HTML documentation is placed in version-specific folders:

- `static/protocol-circuits-api/next/` - Current development version
- `static/protocol-circuits-api/v1.0.0/` - Version 1.0.0
- `static/protocol-circuits-api/nightly/` - Latest nightly version
- `static/protocol-circuits-api/devnet/` - Latest devnet version

The docs are served at `/protocol-circuits-api/<version>/index.html`.

## Versioning

When creating a new documentation version:

1. Generate the API docs for that version:
   ```bash
   ./scripts/protocol_circuits_docs_generation/generate_protocol_circuits_docs.sh v1.0.0
   ```

2. The MDX wrapper page (`docs/developers/docs/resources/protocol-circuits-api.mdx`) automatically detects the current Docusaurus version and links to the appropriate API docs folder.

## Generated Content

The documentation includes all crates in the noir-protocol-circuits workspace:

### Core Library Crates

- **types** - Foundation types, ABIs, addresses, merkle trees, constants
- **private-kernel-lib** - Private kernel circuit logic, validators, and composers
- **rollup-lib** - Rollup circuit logic (tx, block, checkpoint, root stages)
- **parity-lib** - Parity circuit logic
- **blob** - Blob data handling for Data Availability

### Binary Circuit Crates

- **private-kernel-*** - Private kernel circuit entry points (init, inner, reset, tail)
- **rollup-*** - Rollup circuit entry points (tx-base, tx-merge, block-root, block-merge, etc.)
- **parity-*** - Parity circuit entry points (base, root)
- **hiding-kernel-*** - Hiding kernel circuits
- Various simulated variants for testing

### Note on Autogenerated Crates

The workspace includes 86 autogenerated variants of `private-kernel-reset` with different dimension parameters. These are included in the generated documentation but can be ignored by most users.

## Styling

The generated docs use their own CSS (`styles.css`) with light/dark mode support. The styling is kept separate from Docusaurus to maintain consistency with standard Noir documentation.
