## Unreleased

**Migration difficulty:** none. Everything below is additive; existing full node, sequencer and prover configurations are unaffected.

### New features

#### Follower mode: run a read-only node that syncs from another node

```bash
--follower-upstream-url <url>            ($FOLLOWER_UPSTREAM_URL)
--followerSyncPollingIntervalMS <ms>     ($FOLLOWER_SYNC_POLLING_INTERVAL_MS)
--followerSyncBatchSize <n>              ($FOLLOWER_SYNC_BATCH_SIZE)
```

Setting `FOLLOWER_UPSTREAM_URL` starts the node in **follower mode**: it replicates every block, checkpoint and L1-to-L2 message from a single trusted upstream node over RPC instead of syncing from L1 and gossiping over p2p, and forwards the transactions it receives to that same upstream. Reads are served from its own local database, so a follower is a full-fidelity RPC endpoint — it just needs no Ethereum RPC endpoint, no public IP, and no keys. Use it to scale out RPC capacity behind a node you already run.

A follower does not re-validate or re-execute its upstream's data, so only point one at an upstream you trust. Any node that runs an archiver can act as an upstream, with no extra configuration.

The validator, sequencer, prover-node, offense-collection and fisherman subsystems must be off, and the admin `pauseSync` and `rollbackTo` endpoints are rejected in follower mode.

See [Follower mode](../../full-node/follower-mode.md) for the full setup, trust model and limitations.

### Changed behavior

#### `ETHEREUM_HOSTS` is now required, and validated at startup

A node started without `ETHEREUM_HOSTS` previously failed with an opaque Ethereum-client error part-way through startup. It now fails immediately with:

```
No L1 RPC URLs configured (set ETHEREUM_HOSTS). Only a follower node (FOLLOWER_UPSTREAM_URL) can run without an L1 connection.
```

**Operator action:** none, unless you were relying on a node starting without an L1 connection — which never actually worked. Follower nodes are the one role that does not need `ETHEREUM_HOSTS`; it is ignored if set.
