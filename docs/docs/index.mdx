## The platform for unstoppable private apps

Aztec is a decentralized Layer 2 on Ethereum for building applications that are private by design, permissionless to use, and beyond the control of any single party. Smart contracts have both private and public functions and state. Private functions execute and are proven on the user's device, so sensitive data never reaches the network. Public functions run in the Aztec Virtual Machine. Aztec is _not EVM compatible_: contracts are written in [Noir](https://noir-lang.org/docs) with the Aztec.nr framework. To learn how it all fits together, start with the [foundational topics](/developers/docs/foundational-topics).

Building with an AI agent? Give it [llms.txt](pathname:///llms.txt), the index of these docs: every page is also markdown at its URL plus `.md`, and the [AI tooling guide](/developers/ai_tooling) covers the rest.
