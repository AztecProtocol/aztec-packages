Welcome to account creation in Aztec! In this guide, we'll walk through how to create and deploy user accounts for your application. Accounts in Aztec are smart contracts themselves, giving you powerful flexibility through account abstraction. Let's learn how to set them up!

## What You'll Learn

By the end of this section, you'll understand:

- How to generate the necessary keys for an Aztec account
- How to create a wallet to hold your account contract
- How to deploy an account contract on the Aztec network
- The difference between sandbox and testnet account deployment
- How to handle fees when deploying accounts

Think of this as setting up the foundation for your users to interact with your Aztec application. Just like creating a user account on a web app, but with blockchain superpowers!
