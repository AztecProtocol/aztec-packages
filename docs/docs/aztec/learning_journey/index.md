## Getting Started

### New to Privacy & Blockchain
Start with **[Phase 1: Why Privacy Matters →](/aztec/learning_journey/phase_1)**

### Experienced with Blockchain, New to Privacy
Consider starting with Phase 1 for motivation, then focus on Phases 2-4 for conceptual understanding.

### Experienced with ZK, New to Aztec
You might skip to Phase 4 (Aztec Architecture) once available, but Phase 1 provides valuable context on Aztec's mission.

## Alternative Paths

If you prefer task-oriented learning over guided journeys, explore the [Build section](/developers) which uses the Diataxis framework for tutorials, how-to guides, reference materials, and explanations.

## Learning Philosophy

This journey is designed around **progressive disclosure** - each phase builds on previous understanding and prepares you for the next level of complexity. The goal is to prevent cognitive overload while ensuring you have strong foundations for advanced topics.
