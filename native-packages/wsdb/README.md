# aztec-wsdb

The world-state DB service: a persistent, content-addressed merkle store behind an IPC contract
(`wsdb_schema.jsonc`, owned by barretenberg's wsdb-ref in `barretenberg/cpp/src/barretenberg/wsdb_ref/`). `cpp/` is the C++ server and its tests, `ts/` the generated TypeScript
client package (`@aztec-foundation/wsdb`) that launches the server binary.

## Dependencies

wsdb compiles no barretenberg header. Everything it needs from outside this directory, except the
schema, comes from one aztec-packages release, pinned by tag in `foundation.pin` (`cpp/CMakeLists.txt`):

| Dependency | Source |
|---|---|
| barretenberg (`bb_poseidon2_hash*`, and the reference world state's `bb_wsref_*` C ABI for the conformance test) | `barretenberg-static-<arch>-<os>.tar.gz` from the barretenberg GitHub release of the tag |
| ipc-runtime (C++, compiled in) and ipc-codegen (the generated dispatch) | a sparse partial clone of aztec-packages at the tag, holding only `ipc-runtime/cpp` and `ipc-codegen` (a few MB) |
| protocol constants (`aztec_constants.hpp`) | `npx @aztec-foundation/constants-codegen@<tag version>`, which embeds its release's `constants.nr` |
| the `wsdb-ref` binary (the differential test, `wsdb_ref_diff.test.cpp`, runs it beside `aztec-wsdb`) | the working tree's barretenberg build, `barretenberg/cpp/build/bin/wsdb-ref`; the test skips without it. When native-packages leaves aztec-packages, take it from the release instead (see the NOTE in `cpp/CMakeLists.txt`) |
| the wire contract (`wsdb_schema.jsonc`) | the working tree, `barretenberg/cpp/src/barretenberg/wsdb_ref/wsdb_schema.jsonc`. When native-packages leaves aztec-packages, take it from the sparse clone instead (see the NOTE in `cpp/CMakeLists.txt`) |

The lmdblib sibling package (`../lmdblib`) is always built from source. The TypeScript client is
generated by `bootstrap.sh` from the same ipc-codegen.

`foundation.pin` is the tag and nothing else; edit it to move the pin.
