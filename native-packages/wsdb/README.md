# aztec-wsdb

The world-state DB service: a persistent, content-addressed merkle store behind an IPC contract
(`wsdb_schema.jsonc`, owned by barretenberg's wsdb-ref in `barretenberg/cpp/src/barretenberg/wsdb_ref/`). `cpp/` is the C++ server and its tests, `ts/` the generated TypeScript
client package (`@aztec-foundation/wsdb`) that launches the server binary.

## Dependencies

wsdb's own code includes no barretenberg header. While it lives in aztec-packages it builds against this
checkout; only the protocol constants come from the release pinned by tag in `foundation.pin`
(`cpp/CMakeLists.txt`):

| Dependency | Source |
|---|---|
| barretenberg's wsdb-ref library: `bb_poseidon2_hash*`, and wsdb-ref behind its FFI entry (`wsdb_ref_ipc_ffi_entry`) for the differential test. wsdb calls only those C functions | built from source in this build, from the working tree's `barretenberg/cpp/src/barretenberg/wsdb_ref/standalone` |
| ipc-runtime (C++, compiled in) and ipc-codegen (the generated dispatch, FFI entry and client) | the working tree |
| the wire contract (`wsdb_schema.jsonc`) | the working tree, `barretenberg/cpp/src/barretenberg/wsdb_ref/wsdb_schema.jsonc` |
| protocol constants (`aztec_constants.hpp`) | `npx @aztec-foundation/constants-codegen@<tag version>`, which embeds its release's `constants.nr` |

When native-packages leaves aztec-packages, all of these come from the pinned release again (see the
NOTE in `cpp/CMakeLists.txt`).

aztec-wsdb serves the schema over IPC (the `aztec-wsdb` binary) and in-process through its FFI entry,
`wsdb_labs_ipc_ffi_entry`, opened with `wsdb_labs_ffi_open` (`wsdb_ffi_service.hpp`). The differential
test, `wsdb_ref_diff.test.cpp`, drives aztec-wsdb and wsdb-ref through their FFI entries with the
generated typed client and requires both to answer every request alike.

The lmdblib sibling package (`../lmdblib`) is built from source as part of this build too. Both it
and wsdb-ref declare the same msgpack-c, so the build has one. The
TypeScript client is generated by `bootstrap.sh` from the same ipc-codegen.

The release publishes aztec-wsdb for linux-x64, linux-arm64, darwin-x64 and darwin-arm64. The host
binary is `build_native`; the other three are `build_cross <platform>`, zig cross builds from
`cpp/CMakePresets.json`.

`foundation.pin` is the tag and nothing else; edit it to move the pin.
