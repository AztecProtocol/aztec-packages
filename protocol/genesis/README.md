# @aztec-foundation/protocol-genesis

The canonical genesis of the Aztec protocol release this package ships with: an empty world state whose
nullifier tree is seeded with the protocol contracts' registration nullifiers, with no prefunded public
data and timestamp 0.

`genesis.json` holds two things:

- `inputs`: everything a world state is initialized with, including the six nullifiers derived from the
  protocol contract artifacts. A consumer can build the genesis world state from these without the
  artifacts.
- `outputs`: the nullifier tree root, the genesis block header hash and the archive root that world state
  reports. A consumer that only needs the genesis block's hash or the archive root reads them here
  without building a world state.

`index.js` exports the same object as `GENESIS`.

A network that prefunds accounts starts from these inputs and adds its own public data, so its archive
root differs from `outputs.archiveRoot`.

Both files are generated by `noir-projects/fnd/scripts/regenerate_genesis_constants.sh`, which derives
the nullifiers from the protocol contract artifacts with barretenberg and measures the roots with the
reference world state. Never edit them by hand.
